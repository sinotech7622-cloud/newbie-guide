            傳送門連結

              發布面談通知
              
        
              
        
              新人代碼請到試算表的「新人名冊」複製，可以一次通知多位。通知會出現在新人的「村長的家」，新人的回覆會記錄在「面談回覆」工作表。
              
        
        
        
              
          
              
          
              
        
              
        
        
        
        
        
              
          
          
        
              
        
              
      
              
      
              
        
              已發布的面談通知
              
        
              新人回覆：讀取中…
              
        
              
      
              
    
              

    
    
              
      
              
        
              回覆技術諮詢
              
        
              申請內容請到試算表的「技術諮詢」工作表查看（開啟表單的 Email 通知，就會收到新申請提醒）。同一個申請編號再次發布時，會以最新的一次為準。
              
        
              
          
              
          
              
        
              
        
        
        
              
      
              
      
              
        
              已發布的回覆
              
        
              
      
              
    
              

    
    
              
      
              
        
              ① 五張 Google 表單
              
        
              在每張表單的「⋮ → 取得預先填入的連結」中，每一題都填入下表的「代號」（英文小寫），按「取得連結 → 複製連結」，貼到對應的欄位。不要勾選縮短網址。「後台更新」表單請在取得連結之後，才替「管理密碼」加上必填與規則運算式驗證。
              
        
              
      
              
      
              
        
              ② 發布到網路的「後台資料」工作表（CSV）
              
        
              試算表「檔案 → 共用 → 發布到網路」，只選「後台資料」工作表、格式選「逗號分隔值 (.csv)」，按發布後複製網址。其他工作表都不要發布。
              
        
              
        
              
          舊版工作表（選用，只有沿用舊版設定時才需要）
          
              
        
              
      
              
      
              
        
              ③ Google 帳號登入（選填）
              
        
              填入 Google Cloud 的「OAuth 用戶端 ID」（網頁應用程式），新人就能用個人 Google 帳號登入雲端存檔，不用自訂帳密。已授權的 JavaScript 來源要填這個網站的網址，例如 https://帳號.github.io。
              
        
        
      
              
      
              
        
              ④ 常用連結（選填）
              
        
              只會顯示在管理者專區，方便快速開啟。沒有權限的人點了也打不開。
              
        
              
      
              
      
              
        
              ⑤ 產生 config.js
              
        
              到 GitHub 專案上傳下載的 config.js（取代舊檔），約 1–2 分鐘後網站就會套用。config.js 裡不含管理密碼。

              雲端存檔
              
      
    
              
    
              
      
              
      
              
        
              
        
              用你的 Google 帳號登入最方便，不用記密碼，換電腦登入同一個帳號就會接回進度。
              
        
              或使用帳號密碼
              
      
              
      
      
      
      
      
              
        
        
      
              
      
              密碼只留在你的瀏覽器，進度會加密後才存進部門試算表，其他人看不到內容。請不要使用公司帳號的密碼；密碼忘記就無法還原存檔。
